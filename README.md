# AutoEncoders: Greyscale Image Colorization

An implementation of deep learning models and Autoencoders designed to automatically colorize greyscale images using fusion techniques and evaluate their accuracy levels.

## 📌 Features & Overview
- **Autoencoder Architecture:** Employs convolutional autoencoders and deep learning fusion techniques for image colorization.
- **Accuracy Analysis:** Includes performance evaluation and accuracy level metrics.
- **Jupyter Notebooks:** Complete implementation steps provided in `AutoencodersImageColorization.ipynb` and `Code10Git.ipynb`.

## 📁 Repository Structure
- `AutoencodersImageColorization.ipynb` - Main implementation notebook for image colorization using autoencoders.
- `Code10Git.ipynb` - Additional experiment workflow and model training code.
- `Automatic_Colorization_of_Greyscale_Images_Using_Deep_Learning_Fusion_Technique_and_Accuracy_Level_Analysis.pdf` - Complete research paper and technical documentation.
